# Word Search Maker
Starter project for an installable Android web app (PWA).

Features: editable title and word list, 34x34 default grid, multiple grid sizes, all eight directions with validation, browser-based A4 PDF download, print/save-as-PDF, offline caching after HTTPS hosting.

## Install on Android
1. Host these files on a static HTTPS site (e.g. GitHub Pages or Netlify).
2. Open the site in Chrome on Android.
3. Open the Chrome menu and select Install app or Add to Home screen.

Service workers require HTTPS or localhost. The app itself uses no external libraries and generates PDFs locally on the device.
